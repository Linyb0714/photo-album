# 周杰伦主题相册物料

## 目录结构

```
jay-chou/
├── covers/          # 专辑封面风格图片 (16:9, 4:3, 3:2)
├── concert/         # 演唱会/舞台照片 (9:16, 2:3)
├── photos/          # 生活照/写真 (混合比例)
├── backgrounds/     # 背景图片 (1920x1080)
└── README.md        # 本说明文件
```

## 推荐图片规格

### 专辑封面类 (横向)
- **尺寸**: 1920x1080, 1920x1280, 2560x1440
- **比例**: 16:9, 3:2, 8:5
- **内容**: 专辑封面、宣传照、音乐作品

### 演唱会类 (纵向)
- **尺寸**: 1080x1920, 1280x1920, 1440x2560
- **比例**: 9:16, 2:3, 5:8
- **内容**: 舞台表演、造型展示、现场氛围

### 生活写真类 (混合)
- **尺寸**: 1080x1080 (方形), 1200x1600 (3:4)
- **比例**: 1:1, 3:4, 4:5
- **内容**: 日常照、造型照、合作照

## 填充说明

1. 将周杰伦相关图片放入对应目录
2. 保持图片质量 (建议 1920x1080 以上)
3. 支持格式：JPG, PNG, WebP
4. 图片会自动扫描并添加到"周杰伦精选"相册

## 默认相册

应用启动时会自动创建"周杰伦精选"相册，包含:
- 10 张专辑封面风格图片
- 6 张演唱会造型图片  
- 4 张生活写真图片

共 20 张精选图片，支持自动轮播和收藏功能。
